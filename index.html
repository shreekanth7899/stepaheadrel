Full K8s architecture, Pods/Deployments/Services, Ingress, Gateway API, ConfigMaps, Secrets, persistent storage (PV/PVC), RBAC, Helm, Kustomize, ArgoCD GitOps, and pod autoscaling (HPA/VPA/Cluster).

KubernetesHelmArgoCD

Terraform & Infrastructure as Code
Days 32–38

TerraformHCLOPA
M6
Git, GitHub & GitOps
Days 39–45

Git internals and object model, branching strategies (Gitflow, trunk-based, GitHub Flow), GitHub Actions CI/CD pipelines, OIDC auth, GitOps with ArgoCD and Flux, and custom GitHub Actions.

GitHub ActionsGitOpsArgoCD

AWS for DevOps Engineers
Days 46–50

VPC architecture, IAM in depth, EC2/ECS/EKS/Lambda, S3/RDS/DynamoDB, CodePipeline/CodeBuild/CodeDeploy, CloudWatch Container Insights, GuardDuty, Security Hub, and AWS cost optimization.

AWSEKSCodePipeline

Azure DevOps & Microsoft Cloud
Days 51–55

Azure Resource Manager, Bicep IaC, Azure AD and Managed Identities, AKS with Workload Identity, Azure DevOps YAML pipelines with approval gates, Azure Monitor, KQL queries, and Defender for Cloud.

AzureAKSBicep

Jenkins & Advanced CI/CD
Days 56–58

Jenkins architecture with JCasC, Declarative pipelines, Shared Libraries for reusable pipeline code, dynamic Kubernetes agents, Kaniko builds (no privileged mode), pipeline security with HashiCorp Vault.

JenkinsKanikoVault

Days 59–60

PrometheusGrafanaOpenTelemetry
